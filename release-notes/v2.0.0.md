## What's new in 2.0.0

**Mosaic is now Tellycine**

- The app has a new name and a new wordmark. The tile-grid icon stays.
- Tellycine has a new app ID (`app.tellycine`), so it installs as a **new app** alongside Mosaic, not over it. Add your playlists in Tellycine, then uninstall Mosaic.
- Everything else works as in Mosaic 1.11.0.

Releases are still signed with the same key, so future Tellycine updates install straight over the top.
